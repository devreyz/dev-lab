# 🚀 dev-lab
Repositório destinado a armazenar pequenos projetos, protótipos, estudos e experimentos de desenvolvimento.  
Cada projeto fica isolado dentro de sua própria pasta, facilitando organização, manutenção e demonstração.

Este repositório também serve como laboratório pessoal para testar ideias rápidas, conceitos novos, animações, algoritmos e interfaces.

---

## 📌 Objetivos do Repositório

- Reunir códigos simples e funcionais para estudo e demonstração  
- Criar uma coleção organizada de mini-projetos  
- Servir como base para treinar lógica, CSS, animações, eventos e APIs  
- Facilitar o compartilhamento de exemplos com outras pessoas  
- Evoluir futuramente para um portfólio sólido de experimentos

## 📘 Como Rodar os Projetos

Todos os projetos deste repositório são independentes.  
Para rodar qualquer um:

1. Abra a pasta do projeto desejado:
```

cd projects/nome-do-projeto

```
2. Abra o arquivo principal no navegador:
```

index.html

```

> Nenhuma instalação é necessária para projetos simples de HTML/CSS/JS.

## 🧩 Criando um Novo Projeto

Para manter o padrão do repositório, use esta estrutura:

```

projects/
└── nome-do-projeto/
├── index.html
├── style.css
├── script.js
└── README.md

```

Dentro do `README.md` do projeto, descreva:

- O que o projeto faz  
- Como executar  
- Tecnologias utilizadas  
- Capturas de tela (opcional)
